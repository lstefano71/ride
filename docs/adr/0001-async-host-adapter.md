# One frontend on an async-only host adapter

RIDE is moving from Electron to Tauri, and both shells must run the same frontend. Electron offered cheap synchronous calls into Node (`@electron/remote`, `showMessageBoxSync`, `fs.readFileSync`), but Tauri IPC is async only. We decided the frontend reaches every platform capability through a single `D.host` adapter whose calls all return Promises, **including in the Electron implementation**, so the frontend is written once against the weaker contract. We accepted reshaping the synchronous call sites (dialogs, file pickers, close prompts) over the alternative of keeping sync calls in Electron and branching per shell. The only sync surfaces are snapshots preloaded before `init` (env/argv/platform facts, and the store contents behind `D.db`, which writes behind).
